Next, add these two APIs to `server.js`. Open `server.js` and add the following **below your POST `/api/requests` route**: ```javascript // Get all pickup requests app.get("/api/requests", async (req, res) => { try { const result = await pool.query( "SELECT * FROM pickup_requests ORDER BY created_at DESC" ); res.json(result.rows); } catch (error) { console.error(error); res.status(500).json({ error: "Failed to fetch requests" }); } }); // Update request status app.put("/api/requests/:id/status", async (req, res) => { try { const { id } = req.params; const { status } = req.body; const allowedStatuses = [ "Pending", "Scheduled", "Picked Up", "Completed", "Cancelled" ]; if (!allowedStatuses.includes(status)) { return res.status(400).json({ error: "Invalid status" }); } const result = await pool.query( `UPDATE pickup_requests SET status = $1 WHERE id = $2 RETURNING *`, [status, id] ); if (result.rows.length === 0) { return res.status(404).json({ error: "Request not found" }); } res.json(result.rows[0]); } catch (error) { console.error(error); res.status(500).json({ error: "Failed to update status" }); } }); ``` Then restart your server: ```powershell npm run dev ``` Open: [http://localhost:5000/admin.html](http://localhost:5000/admin.html?utm_source=chatgpt.com) You should now see your submitted requests in the dashboard. **Next, we should make the admin dashboard look professional with dashboard cards, responsive table styling, status colors, and a request-tracking page.**
