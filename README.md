#Smart Waste Collection & Recycling Platform

A software-based platform for managing waste collection requests and encouraging responsible waste disposal.

The **Smart Waste Collection & Recycling Platform** allows users to select a waste category, provide pickup details, schedule a collection, and track their request status. An administrative dashboard allows collection teams to view, search, filter, and update pickup requests.

---

## Project Overview

Waste disposal can be difficult when users are unsure about the correct waste category or how to request a collection service.

This project provides a simple digital solution where:

### Users can

- Select a waste category
- Enter pickup location
- Schedule a pickup
- Submit a collection request
- Track their request
- View request status

### Administrators can

- View all collection requests
- Search requests
- Filter requests
- View collection statistics
- Update request status

---

## Objective

The objective of this project is to make waste collection more organized and accessible by connecting users with collection services through a simple web-based platform.

The application focuses on the core waste collection workflow and is designed as an MVP suitable for rapid hackathon development.

## Features

### Waste Category Selection

Users can select from different waste categories:

-  Organic Waste
-  Recyclable Waste
-  E-Waste
-  Hazardous Waste
-  General Waste

### Pickup Location

Users can provide their pickup address while submitting a request.

### Pickup Request

Users can submit:

- Name
- Phone number
- Waste category
- Pickup address
- Pickup date
- Pickup time
- Waste description

### Pickup Scheduling

Users can select their preferred:

- Pickup date
- Morning
- Afternoon
- Evening
